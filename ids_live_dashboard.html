Local Lab Setup & Python Scapy Backend Guide

Instructions for bridging this interface with live Linux network sockets using Scapy and Python.

Architecture Overview

This project uses a raw packet sniffer built using Python and Scapy attaches to a network interface (e.g., eth0 or wlan0). As packets arrive, packet headers are parsed, features are extracted (IP rates, TCP flags, port frequencies), and checked against the rule engine. Detected anomalies are streamed via WebSocket or HTTP API to this dashboard interface.

Live Packet Capture Backend Setup (ids_sniffer.py) 

# Live capture runs in app.py (Python + Scapy + Flask-SocketIO).
# Install dependencies: pip install -r requirements.txt
# Start backend: python app.py
# Open http://127.0.0.1:5000 in your browser.
# Select the interface that sees your traffic (lo for localhost, eth0/ens33 for VM LAN).
# Optionally enter Apache server IP and port 80 (or 443); blank IP and port 0 means all.
# On Kali Linux install libpcap and run with sudo for packet-capture permissions.

Setup Steps (Linux / macOS)

  1. Install dependencies: pip install scapy flask
  2. Identify your network interface: ip a or ifconfig
  3. Execute sniffer with raw socket permissions: python app.py
  4. Simulate traffic using Nmap: nmap -sS -p 1-1000 127.0.0.1

Troubleshooting & Permissions

  • Permission Denied Errors: Packet capture requires root privileges (`sudo` on Linux/macOS or Administrator prompt on Windows).
  • Windows Requirement: Requires Npcap or WinPcap installed with "WinPcap API-compatible mode" enabled.
  • Promiscuous Mode: Ensure your network card supports and has promiscuous mode enabled to inspect adjacent subnet traffic.
